# Projeto de Desenvolvimento de Sistemas para Internet 2026

## Catálogo dos projetos trabalhados na disciplina de PDSI - ano 2026

### Gabarita IF v2
- Equipe: [Anna Beatriz](https://github.com/beagginn), [Gabriela Maia](https://github.com/gabrielafmaia) e [Willianny Ritchelly](https://github.com/WilliannyLima)
- Descrição: Gabarita IF é um sistema educacional desenvolvido para apoiar estudantes na preparação para o Exame de Seleção do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Norte (IFRN). Esse projeto é a continuação do Projeto Integrador. Nessa nova versão, os principais objetivos são melhorar as funcionalidades do sistema e avaliar a usabilidade a partir de testes aplicados com o público-alvo.
- Github: https://github.com/gabrielafmaia/gabarita-if

### SoloSync
- Equipe: [Carlos Eduardo](https://github.com/eduardolemoscosta) e [Luiz Felipe](https://github.com/luizfelipegit)
- Descrição: SoloSync é um sistema web voltado para a gestão agrícola e o monitoramento inteligente de recursos no campo, com foco em otimizar o manejo produtivo, centralizar dados da produção e facilitar a tomada de decisão nas rotinas agrícolas.
- Github: https://github.com/eduardolemoscosta/SoloSync
